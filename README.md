# portfolio-api

API REST para gestionar clientes, cotizaciones y proyectos, con un panel de resumen. Está hecha con Spring Boot y usa PostgreSQL como base de datos. Para correrla hay que crear una base de datos llamada `portfolio_db`, definir la variable de entorno `DB_PASSWORD` con la contraseña de Postgres y ejecutar `./mvnw spring-boot:run`; queda disponible en `http://localhost:8080`.
